- **Branch**: `feat/long-form`

## Tasks

### Task 1: Store Document & Chunked Draft Persistence
- Implement document / longform session draft table and CRUD in `crates/narad-core/src/store/document.rs`.
- Incremental appending of transcribed chunks with optional speaker tag (`Speaker 1`, etc.).
- Unit tests for crash-proof draft recovery and document assembly.

### Task 2: Continuous Chunked Audio Processor & Diarization Stubs
- Implement `crates/naradd/src/longform.rs`:
  - Splits continuous long audio into chunks on natural pauses or duration threshold.
  - Transcribes each chunk and appends to current document in store.
  - Emits D-Bus progress signal `DocumentUpdated(doc_id)`.
  - Non-insertion guarantee: does NOT invoke `insert_text`.

### Task 3: Dashboard Meeting Document Viewer & Impeccable Shape Pass
- Implement `dashboard/src/routes/meetings/+page.svelte` (or document viewer in `/history`).
- Displays meeting title, duration, speaker blocks with timestamps, and export action (Markdown, text).
- Quiet Precision design tokens, standard focus rings, and full verification test pass.
